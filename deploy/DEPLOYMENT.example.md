# 部署记录模板

此文件只提供记录结构。实际记录保存为被 Git 忽略的 `deploy/DEPLOYMENT.md`。

- 服务地址：填写服务器 HTTPS 地址。
- 项目目录、当前发布目录及上一发布：按实际环境填写。
- 发布包 SHA256、发布日期和代码提交：每次发布前核对。
- 服务：网页静态服务、独立小助手及作业后台、Nginx。
- 运行要求：Node.js 22.13+；当前后台固定验证版本见项目README。

## 私有配置和数据

密钥、访问码、会话、原件、SQLite数据库及备份放在发布目录之外，设置最小读取权限，不上传到 GitHub。具体配置方法见 [部署说明](README.md)、[作业说明](../docs/homework.md) 与 [小助手说明](../docs/assistant.md)。

## 发布检查

构建前运行 `npm run typecheck` 和 `npm test`。按部署说明构建前后端和发布包，核对摘要；新建独立发布目录，确认备份和回退版本可用后切换。发布后检查HTTPS、服务健康、认证保护和必要的实际功能，不在公共记录中写入孩子资料。

## 回退

保留上一发布目录。切回旧代码时保留私有配置与学习档案；涉及数据库格式变更时，先明确向后兼容情况，不能用旧数据库副本直接覆盖新增学习记录。
