# 课内小练习与课程资料库

## 已确认的产品规则

语文、数学、英语分别生成约15分钟纸笔练习；一科一天一份。真实完成每份奖励2小脚步，一科每天最多一次，正确率不影响完成奖励。补做旧练习按实际提交答卷的日期计入奖励上限，不按旧题单日期额外发放。家长核实实际完成与更正题目结论是两个操作。

只使用已确认课内的错题。原作业明确写课外时沿用课外；课内外均有、未写清归属时留待分类，由家长修正。课外题独立保留，不进入课内题源。四年级第二学期是家庭目前确认的阶段，教材具体版本和已学单元仍待补充，不能凭上海地区猜测。

## 页面入口

作业首页“小练习”“课程资料库”，详情导航也可打开；错题本有学科与课内外筛选。学习档案在家长设置中维护，成长页也显示。新功能各有两页图文教程，问号打开、翻页、单张下载。

1. 家长先在错题本确认课内题归属，补充学习档案。
2. 孩子进入小练习，选择一门主课。系统根据错误次数、复测结果和间隔排序，取最多4个来源设计3–8题、预计12–18分钟的变式练习。独立解题核验通过后发布；不出缺失图形、依赖音频或开放作文的题目。
3. 下载可独立打开打印的HTML文档，或点“打印／另存PDF”。题单不含答案，家长可以单独保存参考答案；不直接连接家用打印机。
4. 完成后在这份练习中上传1–3张完整答卷。浏览器自动缩图、转JPEG，保存实际上传的压缩答卷，照片固定绑定练习，不参与普通作业自动匹配。
5. 两次独立识读与求解一致才确认对错；缺页、字迹或结论有争议先待确认。家长可更正并保留依据，或核实实际完成领取奖励，不会把待确认强行改对。
6. 复测记录关联来源错题，新错题也保留来源链；一次答对不宣称永久掌握。

## 资料库的范围

先提供封面、版权页、目录、当前单元及近期学校练习即可，不必最初上传三科全书。支持20MB以内PDF、JPEG、PNG、WebP、HEIC原件，资料可按单元分组。单份资料最多30个原件，全库原件预留上限512MB；实际超限会明确提示。

保存原件不自动调用AI；家长选择原件页序，每次1–8页，再排队整理。PDF原件页序可能不同于书上印刷页码。系统保留单元、知识点、整理文字与原文件/原页的对应关系，家长可以逐页修正OCR内容，修正历史保留，再整理不会覆盖家长更正。

出题时只取匹配科目、年级、学期的课内资料，最多3份、每份最多2页与有限补充说明。未整理页面仅保存，不声称系统已阅读全书。当前实现不是全文检索系统，也不通过模型记忆补齐未提供的教材页。课程原文是学习资料，不是执行指令。

## 记录与限额

- 生成与批改按科目日期保持同一题单；同一组照片重试提交幂等，跨练习复用相同JPEG字节被拒绝。更换角度或重新编辑的照片不承诺视觉去重。
- 生成一次通常2次AI调用（生成、独立校验），批改一次通常2次（两次独立核对）；均计入已有家长可改的AI日限额。资料每组选页整理通常1次，不自动逐页重试。
- 一个处理阶段最多尝试2次，失败明确显示，家长决定重试；不会无限自动重跑。缓存仅存校验合格的结构结果，有效结果可复用。
- 同份题重传按当前结果计算复测次数，不把每次识读重试加到复测次数；历史答卷和各轮原始AI结果保留，家长更正另有前后值与理由审计。
- 通过率 = 确认正确题数 / 确认对错题数；未作答、待确认分别显示，均不计入该比例分母。
- 完成奖励以唯一账本事件“科目+实际提交日期”限制；跨学习/奖励数据库用持久收据恢复，重启、重复批改和多份旧题单不会多领。AI聊天不能修改记录或发币。
- 新增奖励上限每天6小脚步，保留生效中的商城价格与期限，后续观察兑换节奏再讨论新一期定价。

## 数据与验证

练习/课程原件、数据库、照片仅存在服务器家庭私有目录，API沿用账号、同源与HTTPS检查；更正、分类、上传课程资料及整理需要家长身份。公开仓库不存实际学校、课本原件、答卷、访问码或模型凭据。

后续维护从 `MEMORY.md`、`docs/TASKS.md` 开始；不能根据静态样例宣称已生成孩子的正式练习。测试使用独立模拟家庭和假的模型回复，不消耗家庭AI额度。

发布维护还需检查`practice_tasks`（queued/generating/grading）与`curriculum_index_jobs`（queued/running），连同原作业、批改、阅读评价队列一起确认空闲后再停服务。原件与数据库一起备份；回退程序不得覆盖发布后新写的学习记录和账本。
