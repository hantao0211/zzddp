# 小步学习小助手

更新日期：2026年11月20日。

小助手定位为孩子使用系统的统一求助入口：不会操作、看不懂提示、处理失败或学习卡住都能问。当前会读取真实功能清单和所选日期的上传状态，给出具体操作指引；上传文件、创建批改任务等尚不能通过对话直接代办，不能声称已完成。

## 使用方式

从 [小助手直达入口](https://14.103.24.55/?assistant=1) 打开，也可以点击网站右下角的“小助手”。首次使用输入家长持有的8位家庭访问码，此设备登录状态保留30天；共享设备可点击“退出设备”。访问码不写入源码或文档。

聊天窗口右上角“更多功能”中提供“复制对话”和“下载文本”。可导出当前页面保留的全部对话、作业日期、修改预览及状态、看图页数、未发送/失败的问题和当前错误编号；不包含登录凭据、原照片或录音。复制失败时提供可长按复制的文本。复制和下载仅在当前设备生成，不新增后台聊天档案；刷新或清空前请先导出。

可以打字提问并连续追问。作业问题优先提示思路，一般知识问题正常解释。小助手按窗口中的日期读取真实备忘录识别、作业提取及查缺记录；初次打开的日期没有资料时，会明确提示已切换到最近有记录的日期。普通提问读取整理记录。说“看看作业”、要求重看照片，或勾选“重新查看当天照片”时，会把当天已转换的页面重新提供给AI，每次最多6页，优先与所问科目或数字相关的页面，界面显示实际查看页数及剩余页数；不会读取其他日期、示例或未上传资料。

作业页面的“和小助手说说这些疑问”可直接带日期打开。先问“系统哪里没看懂”，再解释缩写、科目或要求。小助手只针对你的明确说明提出修改，显示科目、标题、要求、作业形式及拟解除的疑问；点击“确认修改并重新查缺”才保存。解释性对话不会自行改清单，重复确认也不重复创建记录。

确认的说明附在家庭档案中，保留原照片及原始AI识别结果；刷新后仍可在小助手查看。创建说明的当前登录会话可撤销同一条目最新的一次有效说明，再重新查缺。新资料到达、清单版本变化或15分钟到期后，旧预览不能保存，需重新沟通。修改清单不代表作业已做完或答案正确。

语音使用顺序为：点“语音提问”并允许麦克风 → 说出问题 → 点“结束录音” → 检查或修改识别文字 → 点“发送问题”。每段最多30秒，到时自动结束。回答可点“朗读回答”，也可勾选“回答后朗读”。设备阻止自动播放时，再点一次“播放回答”。

关闭窗口会停止当前录音、等待和播放。麦克风未授权、不支持录音或语音服务不可用时，可以继续打字。移动设备的权限提示和自动播放行为需以实际浏览器为准，不保证所有内嵌浏览器都提供麦克风。

## 数据与权限

- 网站使用同源 HTTPS 接口调用服务器，模型密钥只存在服务端环境中。DeepSeek 负责问答、语音识别及合成。
- 访问码以加盐 scrypt 哈希验证；会话使用随机令牌及 Secure、HttpOnly、SameSite=Strict cookie，服务端只存令牌哈希。写请求验证 Origin，HTTP 不提供助手接口。
- 家庭访问码同时保护小助手与真实作业空间，当前家人共用，完整独立成员权限尚未上线；示例里的角色切换仍为演示。
- 本次聊天保存在页面内存，刷新后清除；服务器为朗读缓存最近回答，最多15分钟，仅对应会话可取，不保存长期聊天全文；确认后的家庭说明，以及选择性提炼的知识和必要依据单独持久保存，可撤销说明或停用知识。
- 录音在浏览器中编码成单声道16kHz PCM WAV，服务器校验时长和格式后转交语音识别；本站不长期保存录音。识别文字、问题、所选日期的整理记录和相关家庭说明会发送到 DeepSeek；请求重看照片时，也会提供选中的当天页面。Nginx 关闭该接口的请求／响应缓冲及访问日志，应用不记录问题、录音、访问码或供应商响应正文。
- 会话、登录限流信息及每日次数保存在独立私有状态目录；不与静态页面发布一起替换。

## 调用限制

未覆盖配置时默认家庭每日最多100次问答、30次语音识别、40次朗读。当前家庭已配置为100次问答、200次语音输入、200次朗读，按北京时间换日。服务端可分别使用 `ASSISTANT_DAILY_CHAT_LIMIT`、`ASSISTANT_DAILY_ASR_LIMIT`、`ASSISTANT_DAILY_TTS_LIMIT` 调整，范围1—5000，非法配置会拒绝启动。每天的计数先保存，再调用外部服务；失败不会自动重试，不会因重启而重置当天限额。重复播放客户端已加载的同一段音频不再次合成。

同一会话每分钟最多10次服务调用，全局最多2个并发付费调用；登录按来源及全局限流，防止公开地址被滥用。每次问题最多1200字，携带最近最多8条、合计12000字上下文。一般问答输出限制2048 token，带作业记录的问答限制4096 token，朗读使用简短回答且最多350字。

达到限制时显示原因，不会生成假回答或自动切换到另一家服务。费用以服务商实际计费为准；这些限制控制调用量，不等同于精确货币预算。

## 运行维护

- 服务：`xiaobu-assistant.service`，独立动态用户运行，仅监听 `127.0.0.1:3091`。
- 运行时：独立官方 Node.js 22.23.5，`/opt/xiaobu-node/bin/node`。未修改系统 Node.js。
- 代码：当前发布目录的 `assistant.cjs`；网页与后台一起打包，后台文件在公开静态目录之外。
- 配置：systemd 读取 `/etc/xiaobu-learning/ai.env` 与 `/etc/xiaobu-learning/assistant.env`，均为 root 私有文件。
- 初次生成的访问码在 `/etc/xiaobu-learning/assistant-access-code`，仅 root 可读，不通过网页或日志输出。
- 私有状态：`/var/lib/xiaobu-assistant/state.json`，由 systemd StateDirectory 管理；文件损坏时停止服务，不能静默清空计数。
- 代理：`/etc/nginx/snippets/xiaobu-assistant.conf`，包含在现有 IP 站点中。

```sh
systemctl status xiaobu-assistant.service
journalctl -u xiaobu-assistant.service -n 30 --no-pager
curl --fail https://14.103.24.55/assistant-api/status
nginx -t
```

状态接口仅表明服务可连接及当前请求是否登录，不会为每次健康检查调用付费模型。更换发布时应保留 StateDirectory 和私有配置，并同时重启网页及助手服务；更新失败可恢复之前的发布及代理配置。

## 提炼知识与识别经验

围绕一个孩子积累知识。小助手从已经聊清楚、今后可复用的简称含义、学习方式或使用偏好中选择性提炼；不把普通问题、一次性作业事实、说明需求的举例或助手未确认的猜测存成知识。多轮解释需要用户明确确认；保存的记忆展示原话依据和来源日期，可在右上角“更多功能”的记忆列表停用。不会把本项目讨论时举的例子预先写进家庭档案。

后续问答按简称关键词和中文词片匹配取回最多8条相关知识；新上传资料识别会带入最近20条有效简称规则及最多12条已确认纠正案例。不是模型微调，也不向其他提供商发送训练集。旧案例只供参考，课号/页码按当前图片填写，清晰的新证据优先。明确更正已有知识时保留版本；不一致且未明确对应旧版本时不自动覆盖。停用知识或撤销纠正后，后续调用不再提供它。

当前以最多500条有效知识为限，依靠关键词和场景检索，不承诺所有同义表达均能匹配，也不承诺手写识别始终正确。旧照片不因增加记忆自动重做；仍保留原始识别结果与原图。普通聊天全文仍只在当前页面，提炼的知识和必要依据单独持久保存，刷新不丢失；聊天全文可复制或下载。

本次通过48项自动测试、类型检查和生产构建。模拟档案的真实AI联调验证了知识提炼、重启保留、新对话检索、不同课号的新备忘录识别及停用；手机尺寸界面验证复制、下载、复制受限回退和记忆管理。真实家庭档案未写入测试规则。


## 手机对话布局

手机端全屏显示小助手，主区域用于阅读和滚动对话。顶部简要显示作业日期和关联状态，点击日期或右上角“更多功能”可切换日期、查看家庭说明和知识记忆、设置重看照片与自动朗读，以及复制、下载、清空和退出设备。辅助面板覆盖主区域，返回对话即可恢复阅读，不持续挤占回答空间。

底部保留语音按钮、按内容适度增高的输入框和发送按钮，输入框最高104像素。长回答默认从开头显示，可向下滚动；键盘出现时按浏览器提供的visualViewport高度调整。浏览器验收覆盖多种手机尺寸、横屏、桌面和模拟键盘可视区域变化；未覆盖实际iPhone键盘硬件。


## 多轮作业说明沟通

最近一轮助手问题和最近几次用户说明单独提供给AI，简短回答结合上一问理解，不要求用户重复标题、页码或整句口令。已确认条目和家庭说明优先；重新查缺期间不再提供旧报告作为当前事实。一次只追问一个影响实际处理的缺失信息，不把没说明的额外预习要求设成关联前提。只有询问整份批改时才解释该功能状态，不在其他话题附带提醒。

可执行的作业说明由程序验证后立即显示修改预览；回答中的操作反馈由实际预览生成，使用真实确认按钮名，不说稍后会出现，也不在确认前声称已保存。当日某项作业与某张照片的对应只保存为当天家庭说明，不自动当作长期简称；已有来源仅指向当日照片的记忆不供后续识别和问答检索。明确教给系统的通用简称和稳定偏好仍可按既有流程提炼。

2026年11月20日此修复通过51项回归与类型检查。真实模型联调只使用虚构档案，验证简短确认直接得到预览、已确认后不再追问、指图不会生成长期记忆、通用规则仍能保存，以及原识别记录不变。未将家庭聊天或真实作业发送给模型用于开发验收。


## 语音额度与完成状态表述

语音输入和回答朗读的每日限额独立于问答额度；到达某一项时只提示对应功能受限，并说明可继续使用的方式。提高配置不会清零已经使用的次数，也不重置登录会话。每分钟请求频率限制继续生效，避免重复操作产生大量调用。

作业照片、批注、备忘录勾选、材料齐全及已确认的作业含义，不等于系统验证孩子已完成复习、已掌握或答案正确。用户问“为什么系统仍不确定”时先解释材料或后台状态，不擅自转成担心孩子复习不好。用户本人报告完成应明确注明来源，不能冒充系统验证。


首页简化后，小助手系统帮助同步真实入口：点“拍备忘录”或“交作业”直接选文件，再“确认上传”；点“查看详情”进入“作业清单”及“历史资料”。首页疑问状态卡可直接打开所选日期的对话。家里仍共用访问码，详情收起仅为减少孩子操作时的信息量，不是成员权限隔离。


当前家庭进一步确认了预习/复习的适用判定口径：无额外书面要求时，有圈画、批注或相关练习痕迹记为已做，清晰完整的对应范围没有动笔记未做，不反复要求朗读、背诵或额外笔记证明。该口径随 `reviewPolicy` 明确提供给问答与整理；其他任务及掌握/正确性判断仍保留原有证据边界。学习痕迹、材料收到与答题正确分开，不把“清单1/3”当作学习完成比例。


首页“查看批改”“我的错题本”连接真实记录；错题卡片的“让小步帮我弄懂”会切换到来源作业日期，带上题目与实际作答继续解释，不需要孩子重新描述原题。原图依然只有明确重看时提供，已保存批改记录可以直接读取。

识字纠正与简称教学分开处理。用户指出手写漏字、漏数字或语音误读时，小助手修正本次条目并给出确认预览；不能把错误读数与正确课号保存成长期等价规则。程序同时拦截明确识字纠正、简称数字与展开课号不一致的候选，并过滤旧的同类污染记忆。已确认纠正仍可作为识别案例，original是旧识别而非孩子真实原文，下一次必须依当前图片数字判断。

家庭说明优先展示每项作业最终合并的完整理解，原话和较早版本折叠保留。问答只接收各项最后生效的说明及其完整requirement，避免旧语音原话反复干扰理解；撤销最后一次说明后恢复上一版本。读取旧日报告时动态补充当前说明，不覆盖原始报告或原识别JSON。
