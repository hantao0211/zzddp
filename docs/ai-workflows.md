更新日期：2026年11月20日。DeepSeek使用 `deepseek-flash`。真实上传、服务器私有原件、持久队列、备忘录拆分、混合作业分科、跨批次关联和查缺已实现；小助手提供问答和语音。独立批改、二次核验、错因分析及真实错题本已接入网页；真实针对练习与复测调度尚未接通，出题校验函数仍是基础代码。详见 [作业整理说明](homework.md)。

## 核心约定

孩子只需要上传当天的手写备忘录和完成后的作业照片或扫描件，不需要选择科目、书名、题号或任务。备忘录作为当天作业清单的依据，AI 负责理解、分科、归组、关联、分析和生成练习。程序负责保存原件、权限、任务调度、结果校验和状态呈现。

## 上传后的处理

1. 保存原件，建立持久化任务；页面立即显示资料已收到。
2. AI 识别备忘录的日期与各科要求，逐项建立任务并保留原文证据。
3. AI 识别混合上传的作业，按内容、书名、页码、题号与日期自动关联，可对应多个科目和任务。
4. 对照清单显示未收到材料、收到部分、材料齐全、等待批改及辨认存疑。照片收到不等于做完，也不等于答案正确。
5. 无备忘录时先保存作业，备忘录到达后重新关联；同一任务多次补交需合并全部相关原件再判断覆盖情况。
6. 模糊或缺页时提示补拍对应页面，不要求家长逐题核对；不确定的判断不能影响积分和掌握程度结论。

模型输出必须通过结构校验，并核对引用的任务、日期与原件范围。重试不能重复建立任务或发放积分。

## AI 出题与复测

上传触发识别与归类；定时任务根据错题、订正和复测历史提前生成练习。每道题须有来源错题、知识点、答案和解析，并经过单独的解题校验才能发布。打印请求优先读取已验证题单，不必现场等待生成。需要追加练习时可提交即时任务。

日程使用 Asia/Shanghai。具体复盘时间、每天额外练习量和费用上限待实际试用确定，不擅自创建固定的凌晨任务。

## 文字与语音小助手

小助手支持孩子打字或说话提问，并可用语音回答。文字和语音共用同一个学习助手，会读取窗口所选日期的备忘录、作业提取、查缺和已确认家庭说明，结合当前会话回答疑问。文档内容仅作证据，不能授权管理操作；普通问答不重复发送图片；用户要求看作业或勾选重看照片时，按当天范围和问题相关性提供最多6页页面，告知实际查看范围。只出现数字不能直接推定是课号、页码或日期。用户明确解释科目、缩写或要求时，AI可提出结构化修改，程序核对目标、原文引用、会话、日期和清单版本，先显示预览，用户确认后追加家庭说明并重新查缺。原件与原始识别保持不变，当前会话可撤销该条目最新说明。

语音流程为：孩子主动按下说话 → 麦克风采集 → 语音识别 → 即时学习问答 → 语音合成播放。支持停止录音、停止播放、查看识别文字和改用打字；不持续后台监听。是否保存原始录音另行确定，当前聊天只在页面内存保存，不长期保存录音。

问答需要即时响应，不能等定时批处理。作业问题优先提示和逐步讲解；一般知识问题正常回答。可朗读文本与排版文本分别生成，避免朗读 Markdown 或长公式标记。

## 密钥配置

在服务器终端以 root 执行部署目录中的 `configure-ai.sh`。脚本隐藏输入，验证密钥及模型列表后保存到 `/etc/xiaobu-learning/ai.env`，文件权限为0600。不会将密钥写入项目、浏览器、日志或命令行参数。先配置一个默认提供商，不自动向另一家复制学习资料。

无需编辑脚本。`study_variable=DEEPSEEK_API_KEY` 中的值是环境变量的名称，不能替换成实际密钥；密钥仅在“请输入 API 密钥（输入不显示）”的提示下输入。配置文件存在但缺少密钥时，脚本允许补齐，验证通过后才备份并替换旧配置；已有密钥的配置仍拒绝覆盖。并发运行的配置脚本由文件锁排除。

若曾把密钥写入脚本并截图，应撤销已暴露的密钥，生成新密钥后通过隐藏输入配置，不将包含密钥的脚本或截图作为普通调试资料传播。

小助手及作业后台通过服务器私有配置读取同一默认模型密钥，不自动向其他服务商复制资料。当前端到端验收采用模拟印刷资料，仍需结合真实手写作业观察效果。小助手的使用、数据保存范围及服务维护见 [小助手说明](assistant.md)。

## 从对话提炼可复用知识

同一次结构化问答可输出至多3条记忆候选，程序核对当前用户说明或多轮确认的原话，选择性保存简称知识和稳定偏好，不保存纯提问、临时事实、举例讨论或未确认猜测。SQLite保留来源与版本，界面可查看和停用。问答按关键词/中文词片检索相关知识，备忘录及作业提取带入有效简称规则和确认纠正样例；知识版本参与识别缓存键。原始识别和原件不覆盖，未自动微调模型。完整聊天存档不是该记忆机制的前提。
