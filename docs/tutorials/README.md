# 小步学习图文教程

四个页签各有两张独立图片：作业、阅读、成长、小步。小练习与课程资料库各新增两张，商城另有两张，共14张。页签顶部的问号打开对应教程，可用按钮、左右滑动或键盘方向键翻页。每张图片可单独保存，正文步骤也提供可访问的文字说明。弹窗使用全站滚动保护，关闭后返回原位置。

图片原件见 `public/tutorials/*.png`，页面加载使用同名 WebP，单张约200–270KB。阅读长图原件仍保留在 `docs/images/reading-guide.png`。小步兔子原件为 `public/mascot/xiaobu-rabbit.png`，页面使用透明底 WebP。

素材通过内置 imagegen 生成。共同提示词：为9–11岁女孩制作小步学习手账花园教程，奶油色纸张、玫瑰粉与鼠尾草绿、手绘水彩铅笔、清晰大字、三步图解。每页准确文字与场景如下：

| 图片 | 标题 | 三步 |
| --- | --- | --- |
| home-1 | 作业手帐·认识今天的任务 | 拍备忘录→核对清单→修改识别错误；非书面作业做完可手动确认 |
| home-2 | 作业手帐·上传与检查 | 点对应作业上传→查看状态→打开详情；疑问先看原图与原因 |
| reading-1 | 阅读手帐·开始阅读 | 添加书籍→接着上次页码→开始计时；页码和时长可调整 |
| reading-2 | 阅读手帐·留下自己的想法 | 用自己的话说一说→保存打卡→和小步聊聊；可打字或语音，其他依据选填 |
| growth-1 | 成长手帐·每一步都算数 | 记录实际完成活动→等家长确认→小脚步到账；家务每天合计一次，课程每周各一次 |
| growth-2 | 成长手帐·把心愿变成约定 | 许愿→家长上架→攒小脚步兑换；先看价格、次数与期限，原约定保留 |
| assistant-1 | 小步陪伴·有问题就来问 | 说出问题→按需附图→一起找思路；最多三张图 |
| assistant-2 | 小步陪伴·看清依据再确认 | 结合对应作业提问→看清解释→需要时确认修改；聊天图不自动归档 |

成长第2页另用 imagegen 修正电影示例为10个小脚步、购物卡为按金额。兔子从阅读第2页提取并通过 imagegen 生成独立透明底素材，保留白色垂耳、绿围巾与雏菊。

压缩可运行 `node scripts/optimize-tutorial-assets.mjs`，保留PNG下载原件。

新增：`practice-1`选主课／打印题单／纸上作答；`practice-2`拍完整答卷／看逐题结果／之后再测。`materials-1`确认阶段／添加教材练习册／上传原件；`materials-2`标明课内外／选择需整理页码／核对来源。小练习第1页通过imagegen将三本书的封面明确修正为语文、数学、英语。

商城新增`mall-1`小卡片／详情／申请，`mall-2`确认／使用／更正记录；成长第2页同步使用新的约定说明，不再宣称生效后绝对不可改价。入口改为每页上方聊天按钮，商城独立页签。
