# 课内小练习需求记录（待教材补充后实现）

学习档案记录用户提供的年级、学期、地区与学校，仅保存在家庭私有状态中，可由家长修改。教材版本待用户提供封面、版权页、目录和当前进度，不能擅自推定版本或已学范围。

目标：语文、数学、英语各有约15分钟纸笔练习；每天每科合计一次2小脚步奖励机会。只使用课内题池；课外错题单独保存和统计，不进入这套课内出题池。沿用原资料中明确分类，无法确定时要求手动分类。

后续实现需包含：

- 学习档案、教材版本及已学范围；材料索引保留科目、课内/课外、单元、页码和原始来源。
- 从已核验错题选择目标，生成变式题，独立求解复核后才能发布。不能将AI未确认、已撤回或缺完整题意的题直接作为出题依据。
- 按错题复现次数、近期复测失败率、间隔和已练次数加权；降低已稳定通过题的频率，保留少量间隔复测；没有足够真实来源时说明原因，不编造学习历史。
- 生成独立打印文档，学生卷与答案分开，标识练习编号、科目、课内、阶段及来源知识点。预计15分钟是题量目标，不通过计时推断认真程度。
- 拍照上传后绑定具体练习编号，避免送回普通作业识别流程或串到别的练习；保存原件，去重和有界重试，显示处理状态与失败原因。
- 批改逐题关联练习题、来源错题与照片证据，独立核验，不把看不清当错误；订正、复测通过率及次数可追溯。原错题不删除，不把单次答对直接写为永久掌握。
- 完成奖励与正确率分开；真实完成一套可获得2小脚步，不能重复提交或反复生成刷奖励。待确认题不误判为未做，允许清晰补拍或家长处理。
- 后台强制每日每科上限、幂等发放、越权检查、AI调用额度；生成失败、空卷、重复照片不发奖励。

当前代码已有生成练习/复核的AI合同、真实错题本与静态打印示例；尚无这套动态练习、上传批改、复测统计的完整闭环。不能把旧的示例练习当作已实现。
