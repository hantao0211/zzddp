# 家庭账号与家长管理

当前为一个家庭、一个孩子的部署。所有学习资料仍归这一个家庭，按成员角色区分管理权限，没有把前端切换视角当作认证。

## 入口与首次开通

孩子学习入口为网站首页；家长管理入口为 `/admin/`，首页下方提供“家长入口”，家长登录后显示“家长管理”。同一浏览器、同一站点的小助手和学习空间共用账号会话。

首次启用账号服务时，后台在服务器私有状态目录创建一次性 `parent-setup-code`（0600）。由家长通过已有的服务器管理员登录读取，在管理页填写开通码、登录名、称呼和密码，建立第一个家庭管理员。默认目录下读取命令：

```sh
sudo cat /var/lib/xiaobu-assistant/parent-setup-code
```

这条命令在网站服务器终端执行；若自定义了 `ASSISTANT_STATE_DIRECTORY`，使用相应目录。不要把开通码贴到普通聊天、公开仓库、日志或URL。开通完成后服务器删除文件并注销开通凭据；其他访客不能通过首次访问或旧家庭访问码注册管理员。已有管理员后不再开放首次开通接口。

## 角色

| 角色 | 能力 |
| --- | --- |
| 家庭管理员 | 全部家长能力，以及新建成员、修改称呼与角色、停用账号、重设密码、调整小助手每日额度、关闭旧访问码 |
| 家长 | 上传和查看学习资料、使用小助手、查看家长学习记录、重试失败整理/批改、查看与停用知识记忆 |
| 孩子 | 上传备忘录和作业、查看任务/反馈/错题、使用小助手、提出和确认本人会话里的作业说明；没有账号、额度、记忆停用和后台重处理等管理权限 |

管理员在“家庭账号”建立孩子和其他家长账号。登录名为2—32位英文、数字、下划线、点或连字符，大小写不区分；密码至少8位。登录时不由客户端选择角色，后端按账号的实际权限确定身份。服务器在每次管理请求重新核对角色，孩子直接调用管理API也会被拒绝。

家长和管理员均可在“修改密码”中输入当前密码并设置新密码，修改后该账号所有设备须重新登录；忘记密码时由管理员重设。家长页有“学习记录”“知识记忆”“修改密码”；管理员另有“家庭账号”“家庭设置”。最近60个有记录的日期提供原件份数、作业数量、批改与异常情况，打开当天学习页查看具体题目和原件。失败任务重试需要家长主动确认，日常自动处理仍在后台运行。

## 兼容原访问码和旧设备

此前的8位家庭访问码及已登录设备保留，只拥有孩子权限，不自动成为管理员。管理员建立孩子账号后，可在“家庭设置”关闭旧访问码；服务器会撤销所有旧访问码会话。重新开启访问码也不会恢复已撤销的旧会话，需重新登录。

## 凭据、会话与维护

账号保存在状态目录下单独的 `accounts.sqlite`，与学习档案分开；密码采用随机盐的scrypt散列，不保存明文。会话仍使用安全、HttpOnly、SameSite=Strict的Cookie，期限30天；服务端保存令牌散列及账号绑定。停用或重设密码会撤销相关登录；修改角色后每次请求立即按新角色判断。不能停用或降低当前管理员自身角色，也不能移除最后一个可用管理员。

家庭账号变更在账号库中留审计，不记录密码。家长开通码、账号库、会话状态和数据库备份均不能提交仓库。管理员每日额度按北京时间全家共用，修改后保留当天已使用次数，设置与会话一起持久保存，网页不展示模型API密钥。后台作业模型调用仍使用原独立配额，未随小助手额度调整。

上线前备份整个私有状态目录。回退旧版会失去独立账号登录及新管理页；不要用旧状态副本覆盖已新增的账号或学习记录。忘记所有管理员密码时需通过服务器管理员身份恢复，不能让持有孩子凭据的网页用户自行提升权限。

当前没有新增删除原件、奖励审批、自动针对练习发布或跨家庭隔离的管理功能。


## 知识记忆的范围与历史

“知识记忆”分别展示可跨作业复用的知识、最近12项当前有效的作业说明、历史记忆。长期知识与某一次照片的对应说明不是同一种记录；长期知识数量为零，不表示作业说明丢失。作业说明已用于对应清单，也作为识别的纠正案例，历史页码和课号不固定套用于新作业。已停用、被新版替代或被规则排除的旧记忆保留来源与原因，但不会作为启用中的长期知识展示。

常用状态采用通用图标、语义颜色和短文字共同表达。正确、错误、未作答、未确认、主观题点评保持区别；照片已收到、作业已做完与答案正确也分开。正确题的详细解法和一般批改说明默认折叠，错误和未确认原因继续直接展示。
