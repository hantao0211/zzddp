# 阅读删除验证

阅读历史和修改界面可删除误记内容。弹窗核对书名、日期、页码、时长；请求带原记录版本并同步防连点。家长可删除家庭记录，孩子仅可删除自己提交的记录。

服务端保留私有原记录与删除审计，所有对外历史、阅读日历、统计与续读都排除已删除项；旧保存不能复活原编号，未完成评价取消，迟到评价不能重新发布。已得小脚步保留，奖励事件键保留以防同日重新录入重复领取。最后一条记录删除后更新打卡日期和当前连续天数。

- 301项自动检查通过：删除权限、版本冲突、重复删除、旧提交重放、统计重算、照片保留、重启、评价并发、原账本保留、登录和同源校验、历史API过滤。
- 类型检查及前后端生产构建通过。
- Chromium／WebKit使用虚构家庭接口，验证确认与取消、慢请求连点、失败保留、删除响应丢失后幂等重试、历史及修改入口、删除后草稿与进度重置，以及320／390深浅色布局。
- 修正统一提示在原生弹窗关闭或卸载瞬间调用popover API的问题；实际删除成功后页面保持正常，提示可见。
- 浏览器验证不写真实家庭、不调用收费AI。指定家庭误记条目仅在备份后按用户明确指示处理。
