# 错题分析核心设计

错题本应能说明孩子反复在哪些知识点和题型上出错、最近的订正和复测有没有改善，以及下一步先练什么。每次上传的作业、订正和复测都积累成可追溯的长期记录。分类既用于筛选原题，也用于生成能回到原题与原图的分析。本文是核心产品约定，新增维度、统计与页面的实现状态见 [任务清单](TASKS.md)。

## 一道错题对应哪些信息

同一道原题、每次独立作答、每次核验或更正分别保存。题目提供稳定定位，作答记录提供发生日期与结果，分类和核验带有来源、时间及版本。系统可以把多次作答关联到同一题，也可以指出两道不同题考了同一知识点。作答记录至少区分原作业、订正和变式复测。

| 维度 | 建议字段与取值 | 记录依据 |
| --- | --- | --- |
| 学习阶段 | 作业所属年级、学期、作业日期 | 以原作业和当时已确认的学习档案为准。作业较早或跨学期补录时允许家长确认，否则保留阶段待确认。升年级后仍可查上一学期的题。 |
| 学科和范围 | 科目、课内／课外／待分类 | 继承原作业信息，保留家长已确认的单题更正。课外资料独立分析，课内出题仅用确认过的课内来源。 |
| 来源 | 作业、随堂练习、单元测验、考试、订正或小练习，另存作业名、大题／小题、原图与教材出处 | 有对应原件就能点回核对。教材版本、册次、单元和印刷页码分别记录。来源缺失时保留待确认。 |
| 作答形式 | 单选、多选、判断、填空、计算、连线、改错、简答、写作等 | 小题记录主要作答形式。阅读理解等整组题保留大题结构，组内各小题可分别是选择或简答。 |
| 任务场景 | 阅读理解、完形填空、看音标写词、听写、应用题、实验探究等 | 同一题可同时有「阅读理解」场景和「单选」作答形式，两个维度都能筛选。例如按阅读理解找整组，或按单选查看跨任务的表现。 |
| 知识点 | 学科下的主题、知识点和细项。注明主知识点，可有次知识点 | 例如「英语 → 一般现在时 → do / does 疑问句」。统一词表、同义词归并，教材单元和知识点分别保留。 |
| 能力 | 识别、理解、运用、推理、表达。学科细项可用定位信息、列式、检查单位、书面表达等 | 根据题目实际要求标记。题目可能考多个能力，区分主要能力和辅助能力。 |
| 错因 | 概念理解、审题或条件遗漏、方法选择、步骤／计算、拼写／书写／单位、表达不全、暂无法判断等 | 与题型和知识点分开。保留支持判断的作答片段及判断来源。孩子或家长可补充原因，一次作答不足时先保留为推测。 |
| 难度和负荷 | 教材标注、基础／综合／拓展、步骤数、可用的实际用时 | 保留来源与信心。主观估计可用于安排练习，只有孩子实际填写的时长才进入用时统计。 |
| 学习状态 | 首次出错、已订正、待复测、复测通过、近期反复出错。保留最近作答及状态变更 | 用实际订正和复测驱动，保留每次证据和历史。一道题可能已订正且待复测。一次答对只记录本次通过。 |

题型、能力和知识点有各自的稳定标签标识。重命名显示词或合并同义词时，历史筛选仍能查到。合并保留旧别名和出处。题型从共同词表选，例如「对错题」统一显示为「判断题」。各科可在共同词表下补学科类型。词表新增项需能解释与旧标签的关系，自动识别优先匹配已有项。题型或知识点无法可靠匹配时显示「待分类」，避免同一个知识点被模型每次换名后分散统计。

## 上传后的分类流程

1. **绑定来源。** 上传后的题目先关联作业、科目、课内外、日期、原件及题号。尽可能从作业来源继承年级学期、单元、教材和大题类型。批改确认结果后才计入相应的对错统计。
2. **分类入库。** 使用已有批改、题干、答案和资料库的知识信息补充作答形式、场景、知识点、能力与错因。可确定的来源字段直接继承。模型根据证据建议标签，每个维度分别记录来源（继承、规则、AI、家长）、置信档和简短依据。题型和知识点明确时可自动归类。待确认标签保留候选，界面区分已纳入统计与待核对。
3. **有针对性地核对。** 家长可在单题修改标签，也可从原作业一次确认同份作业的共享字段。单题手动更正优先于来源继承和自动更新。孩子可以查看标签和原题，并可补充自己的订正说明。后续新增教材目录或单元资料时，只重新匹配有影响的待分类记录。
4. **增量累积。** 对新作业只处理新增或变化的题。优先复用已有 OCR、批改和教材索引，标签任务按已有 AI 额度安排，识别失败保留当前可靠字段。缓存依据题目内容、来源修订及分类规则版本，同一输入重试幂等。改题干、改标签或更正判定后，更新受影响的统计和后续练习推荐。
5. **逐步补旧数据。** 优先用已有资料恢复阶段、科目、课内外、题号和可判断的题型，按历史作业分批补标签。保留原题、原图和旧复测链。家长手动结论与历史订正时间保留。来源不明、无可靠作业日期或教材版本的记录在列表可查，并分别显示未知字段。

## 筛选和对照

错题列表首层提供年级学期、科目、题型、课内外。更多筛选提供日期、来源、单元、知识点、能力、错因和复测状态。每张题卡只显示有辨识度的标签，详情给全量维度和证据。不同维度组合求交集，同一维度多选取并集，例如「四年级上学期＋英语＋课内＋单选或填空＋do / does」。

保留「待分类」「暂无复测」筛选，每页只取当前页的摘要，详情按需打开。筛选后的总数由服务端按同一条件计算。长期分析页与单题错题本共用筛选口径，点一个分析项能查看对应错题。切换错题本的筛选只改变当前视图，小练习仍按已保存并已确认的课内数据独立计算候选。

## 长期分析用什么数据

错题本回答“哪里错过”，各科、题型或知识点的错误率还需要确认正确的题。逐步把已经核验的正确和错误作答同时纳入分析，保留原作业、小练习、订正等来源分组。数据不足时展示已录入的次数和缺失项。

| 指标 | 计算方式 |
| --- | --- |
| 错误次数 | 某维度内，被确认判错的独立作答数。展示它来自几份作业、涉及几道原题。每次批改重试、同次作答重复上传或标签重算只保留一次计数。 |
| 原作业错误率 | 原作业确认错误题数 ÷ 原作业确认对错题数。待确认、未作答及缺页分列。只保存错题的历史区段显示错误次数，错误率标明数据不足。 |
| 复测通过率 | 独立变式复测确认正确数 ÷ 复测确认对错数，显示样本数、轮次、最近日期，未作答及待确认分列。复做原题和变式复测可分别查看。 |
| 观察趋势 | 按周、月、学期查看错误数、错误率和复测通过率。对照时显示两期各自的确认题数及记录覆盖，优先比较同科、同范围和可比题型。 |
| 优先提升项 | 看同一知识点在几份不同作业上反复出错、近期是否仍错、变式复测表现怎样。给出推荐依据、对应记录和下一次练习建议。样本少时标明继续观察。 |

一题贴多个标签时可出现在各标签的明细中，同一查询的总计按作答事件去重。按主知识点汇总时，每次作答只归入一个主类。新一次答对会改变当前复测状态，原错记录继续用于历史趋势。家长更正使统计批量更新，保留修订记录用来解释数字为什么变化。评论应聚焦孩子当时做了什么和接下来怎么练。

**示例。** 某阶段英语课内题中，孩子在三份作业的 9 道 do / does 疑问句里有 4 道确认错误，错误集中在第三人称单数，最近一次仍错。系统可给出「do / does · 建议优先练习 · 4/9」并链接四道原题。本周安排少量不同场景的变式，下周记录间隔复测结果，显示是否改善和值得继续观察的部分。示例为虚构数据。

## 实施顺序与验收

1. **结构与标签。** 用稳定题目定位把现有错题、作答和复测串起来，补阶段快照与标签的来源、版本和手工覆盖规则。覆盖同图重复上传、同份重批、发现来源更新、跨学期补录和旧档案导入。
2. **上传自动分类与筛选。** 在现有批改之后接入增量分类，建立学科、范围、年级学期、题型和知识点索引。先把常见题型及三科知识点做扎实，再扩充覆盖。确认新题可自动出现，多维筛选联动正确，未知和人工修正可回查。
3. **统计与复测闭环。** 先展示次数、样本数和原件回查，再补分母齐全时的比率和趋势。用同一知识点在不同作业反复出错及后来变式通过的模拟场景验证统计、练习优先级和状态变化。真实孩子记录、原图和答卷跟随家庭权限，公开文档与测试仅用模拟数据。
