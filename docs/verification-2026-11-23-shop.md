# 商城卡片与顶部操作栏验证（2026-11-23）

本轮支持家长选择12种商品图标，独立图标修改不改变价格、期限、约定版本或旧兑换。旧商品按名称给出默认图标，不改写商品约定。商城手机保持两列，图标与名称同行，卡片接近正方形，完整说明和日期在详情中查看。顶部聊天按钮与其他操作同行，手机用兔子图标节省空间。

## 已完成

- 290项自动检查、类型检查、前后端生产构建通过。
- 新增覆盖：图标持久化、旧商品默认展示且原行不变、只允许家长修改、拒绝图标接口夹带改价、原约定与账本不变。
- Chromium与WebKit已通过：320/390/768/1280宽度、深浅色、手机两列且卡片比例、名称和图标水平对齐、顶部聊天不换行、图标重载后保留、完整详情及聊天草稿跨页保留。
- 最后一次调整仅将简短截止日期放到卡片底部同行，最终构建已经过Chromium与WebKit复验。功能提交`d0e6341`已推送GitHub并发布。
