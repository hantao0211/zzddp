# 家庭学习助手产品需求与第一版计划

记录已确认的需求、建议的交付范围及需要验证的条件，作为原型和开发的依据。更新日期：2026年11月20日。

## 产品目标

让孩子在家长无法每天陪伴时，也能持续记录学习、完成任务、得到反馈；帮助家庭了解问题及后续安排，同时逐步培养孩子独立学习的能力。

成功不能只用登录次数、积分或做题量衡量，还应观察同类错误是否减少、间隔复测是否能独立完成、孩子能否主动开始和说明困难，以及家长实际投入的时间。

## 已确认的使用背景

- 面向上海小学阶段，覆盖数学、英语、语文，支持按重点科目逐步扩展。
- 多位家庭成员可以录入，账号权限不同，孩子缺少高级管理权限。
- 学校材料主要为纸质，试卷通常已有老师批改；系统也需要自动批改及复核。
- 孩子可独立使用平板和手机，练习优先在纸上完成，也保留在线作答方向。
- 家里有打印机，期望首次配置后日常一键打印；支持拍照和扫描上传。
- 每天备忘录记录的作业要求、完成后的作业都需要保存统计。
- 不接受家长逐题核对作为正常使用前提，家长时间有限。
- 持续观察、学习效果和主动意愿都重要；奖励机制和商城属于产品方向，具体规则待设计。

## 已确认的核心需求

### 日常资料收录

备忘录、日常作业、练习、考试及订正材料均可上传。支持多页批量上传，保存原图、来源、日期、上传人以及资料之间的关联。系统识别科目、作业要求、题目、作答、老师批改；识别结果允许重新处理并保留修订历史。

备忘录用于建立当天作业清单，完成材料关联对应任务。上传成功、内容完整、作业完成和批改通过是不同状态，不能直接等同。缺少证据时明确显示待确认，不自动判定孩子漏做。

孩子不需要手动分科或选择关联任务。AI根据每天备忘录拆出各科清单，再结合上传作业的内容、页码、题号和日期自动关联，支持一批资料对应多个科目及任务。先上传作业也应保留，待备忘录到达后重跑匹配。

没有额外书面要求的预习复习可按家庭约定的动笔痕迹检查；纯朗读、背诵和明确额外要求仍按其具体要求处理。

### 自动批改与分歧处理

系统能批改针对练习，复核学校作业与试卷。保留孩子原始作答、老师批改和系统判断，禁止覆盖原始记录。

区分识别不清、答案判断不确定和师生批改分歧。先重试识别、重新校验解题过程；仍不能确定时保留待确认状态，不强行计入错误统计、积分处罚或掌握程度结论。异常不能成为要求家长每天逐题审核的入口。

生成题目必须同时准备并校验答案及解析；无法确定题目或答案可靠性时不发布。开放题保留评价依据和适用范围，能力按科目与题型分阶段交付。

### 错题与后续安排

错题保存原题、作答、答案、解析、知识点、判断依据及订正和复测历史。问题原因属于可修正的分析，不能仅凭一道题把孩子定性为粗心或不认真。

结合正确题、错误题和复测结果观察掌握情况。支持原题复习、同类变式、间隔复测；学校作业较多时减少或暂停额外任务。不能从照片数推算学习时长，也不能把未上传等同未学习。

### 打印和回传

首次由成人配置打印机及默认选项，日常由孩子点击打印任务。自动排版并携带任务标识，上传后自动匹配作答。支持拍照、扫描、多页归并及重试，避免让孩子重复录入纸上答案。

真实一键发送打印与系统打印对话框应明确区分。浏览器打印功能只能作为可用的回退方式；直接发送至打印机需验证设备协议、厂商支持或家庭端打印服务。

### 学习档案与统计

保存每日任务、资料、批改、订正、练习、复测和分析历史。提供按科目、日期、知识点查询及简短家长周报，呈现依据、进步、未解决的问题和需要介入的具体事项。

### 自主学习与奖励

孩子可以查看任务、请求提示、记录疑问、回顾进步。建议逐步加入任务选择和自定目标，随着熟练程度减少提醒。

积分、奖励清单及兑换流程的方向已提出，规则尚未确定。建议奖励尝试、订正、坚持和自主安排，允许记录线下学习；不可把拍照次数当作努力或只按正确率发奖励。

### 文字与语音小助手

小助手是孩子使用整个系统的求助和办理入口，不只是学习题目问答。不会上传、不懂提示、处理失败、不知道下一步，均能用自然对话或语音求助；应结合实际页面和资料状态，提供短步骤、入口或可执行操作。涉及修改或重要结果时展示预览并确认。未接通的功能明确解释当前情况，不用“系统边界”等抽象说法推回孩子。不能伪称已经执行操作。

自动批改仍是必须完成的核心需求，不能因为小助手尚不能发起批改而从范围中删除；逐题保存、老师判断复核、不确定性处理、错题和后续练习需要实际闭环。

聊天提供复制及文本下载，包含问题、回答、修改状态和错误提示，方便家庭分享排查。当前普通聊天仍只存在页面内存；记忆的核心是从已聊清楚的交流中提炼有效知识和识别技能，后续识别与问答检索复用，不是把聊天全文机械塞进上下文。围绕一个孩子积累；说明需求的例子不作为真实记忆预先录入。知识需保留依据和适用场景，可更正、停用，避免反复询问同一简称。

孩子可以通过打字或语音提问，助手结合本人已授权的作业与错题即时讲解，并可语音回答。支持主动录音、停止录音、停止播放和文字回退。作业问题优先分步提示，培养独立思考；不能访问其他家庭成员资料。语音接口、HTTPS与手机平板实机验证纳入交付。

## 建议的权限模型

以下作为原型默认方案，具体授权可调整。

| 角色 | 默认能力 |
| --- | --- |
| 家庭管理员 | 管理家庭成员和权限、奖励规则及全家学习记录 |
| 家长成员 | 上传资料、查看授权范围内的分析、安排任务及处理兑换 |
| 孩子 | 上传本人资料、查看本人任务、提交练习、看反馈与申请兑换 |

孩子不能修改权限、积分规则或自行确认兑换。服务端应检查每次读写权限，家庭资料按家庭及孩子隔离。

## 建议的第一版范围

### 第一阶段 交互原型

使用模拟资料验证以下页面和操作，不代表真实识别、批改、打印或持久化能力已经实现：

- 孩子首页：今日作业、上传入口、打印任务、处理进度和反馈。
- 备忘录与作业上传：批量选择、自动关联结果、识别存疑状态。
- 资料详情与错题：原图、作答、老师批改、系统判断、订正记录。
- 练习单：任务内容、打印预览、作答回传及复测安排。
- 家长概览：本周记录、进步、关注问题和家庭成员权限入口。
- 简单成长与奖励展示，具体发放规则另行确认。

### 第二阶段 可持续记录的基础版本

实现真实登录和权限、私有文件存储、备忘录及作业归档、任务状态、批量上传和资料查询。数学优先接入识别与批改验证；英语语文先支持完整存档。

### 第三阶段 数学练习完整流程

在已验证题型范围内实现自动整理、批改、错题、题目生成与答案检查、打印、回传、复测和周报。根据家庭设备测试结果实现直接打印方案。

### 后续扩展

深化英语语文分析、在线练习、口头作业记录、可配置奖励商城及更多学习计划能力。仍需按实际使用效果决定顺序。

## 第一版验收方向

| 场景 | 预期结果 |
| --- | --- |
| 上传备忘录与多页作业 | 保留原图，生成清单，自动尝试关联；重复请求不会重复建立任务 |
| 上传中断或识别失败 | 已上传资料保留，状态清楚，可重试，不把失败计成孩子未完成 |
| 题目或作答识别存疑 | 可追溯原图，待确认内容不计入确定的对错和掌握结论 |
| 老师与系统判断不同 | 两份判断均保留，能看依据，不默认任何一方必然正确 |
| 打印系统练习并回传 | 能匹配原任务、题号与作答，保留批改及订正记录 |
| 重复点击打印 | 区分发送中、失败和重新打印，避免网络重试引发重复发送 |
| 孩子越权操作 | 服务端拒绝修改角色、奖励规则及其他家庭资料 |
| 家长查看周报 | 能看到依据和待关注事项，不需要翻看全部原始照片 |
| 孩子独立使用 | 能在一次引导后完成常见上传、查看任务和打印操作；实际通过设备试用验证 |

识别和批改的准确率、响应时间及每日操作负担，应在代表性样本试用后制定量化门槛。原型阶段不承诺未经验证的指标。

## 数据基础

建议按家庭、账号与角色、孩子档案、原始资料与页面、每日作业清单、题目与作答、批改判断、知识点、错题与复测、练习与打印任务、积分流水与兑换记录组织数据。

原始资料与衍生分析分开保存；记录模型及规则版本和判断依据，支持更正与重算。学习资料私有存储，代码仓库只放模拟样本；提供备份、导出和删除能力，删除时覆盖原件与对应衍生数据。

## 下一步交付

当前已接通单家庭真实后台：家庭访问码、私有原件存储、持久化队列、备忘录拆分、混合作业归类关联、缺交材料跟踪、作答覆盖检查、独立批改核验及错题本。文字与语音小助手支持系统帮助、确认后的家庭说明、选择性知识记忆与识字纠正。独立家庭账号和家长管理页已接通；AI针对练习发布、复测、定时复盘备题、奖励和直接打印仍待实现。

详见 [后台AI与小助手工作流](ai-workflows.md)。

网站、原生应用和家庭端打印服务的最终组合尚未确定；建议先验证适配手机和平板的网站能否满足日常使用，再根据设备能力补充应用或打印组件。
