# 小步学习界面与操作约定

采用“清爽学习桌”的白色扁平表面，结合“专注下一步”的简短引导。主色为灰粉色 #a95476，背景 #f9f7f8，主要文字 #343039，次要文字 #736b75。粉色用于选中状态、主要动作与小脚步，正确/错误/等待状态继续配通用图标与文字，不仅靠颜色。

孩子的固定导航为“作业、阅读、成长、小步”。宽屏使用侧边导航，手机和平板使用底部导航，并为系统安全区及滚动内容留足空间。家长设置独立放在设置图标或侧栏底部，修改权限仍由服务器判断；孩子只能打开家长登录入口。账号菜单展示当前身份并提供退出。

作业首页先显示日期、下一步简短提示、交作业/拍备忘录。作业进展同时显示照片接收与完成状态，已有批改入口及错题本仍保留；不能将照片已收到等同已完成或已做对。识别依据、档案及旧记录按需进入详情，不在首页重复。电脑侧栏仅使用已登录家庭的真实阅读概况，不放演示分数或虚构书籍；资料暂不可用时只显示阅读入口。

阅读与成长在同一页面内切换，保留正在编辑的页码、概括、照片及计时状态，地址和浏览器前进/后退同步。有未保存的阅读内容时离开页面触发浏览器提醒，阅读计时仍按原有设备恢复规则运行。更换登录账号重新读取资料并清理前一身份的编辑状态。书籍进展、连续记录、心愿及小脚步来自现有接口，界面改造不修改积分规则或历史记录。

小步入口在各页保持同一位置，通过导航打开现有对话窗，普通打开/关闭不清空对话或草稿。手机继续为对话保留主要空间，设置、记忆、导出和照片重看收在更多功能里；窄屏、横屏及软键盘高度变化均需验证。阅读场景使用阅读问题示例，不混入作业问题。

触控动作至少44像素高，输入框16像素以上，正文以16像素为基准。按钮保留文字和图标，禁用/等待有明确反馈。真实上传继续直接打开设备选择器，再确认上传，不重复要求日期、科目和关联任务。大插画、悬浮入口遮挡内容、无依据的学习评分和催促排名不进入孩子常用页面。

发布前使用隔离模拟家庭检查320、390、768、900及1280宽度，覆盖真实上传协议、家庭权限、阅读草稿/计时、许愿审批/兑换、对话/语音/导出及历史功能。测试资料不进入正式数据库。
