# 小步学习界面与操作约定

采用适合9—11岁孩子的“手帐花园”：奶油背景 #f5efe5、暖白纸面 #fffdf7、玫瑰粉 #b44b64，辅以鼠尾草绿 #dbe5d5、浅黄和淡紫。文字 #493a3d，次要文字 #6f5e60。桌面采用侧栏和活页纸布局，手机采用窄纸边和固定底部导航。活页纸与小花盆仅作轻量装饰，不遮挡内容；作业、阅读、成长、小助手及弹窗共用纸面与配色。正确、错误、等待保留独立的通用图标、颜色和文字。

孩子的固定导航为“作业、阅读、成长、商城”。宽屏使用侧边导航，手机和平板使用底部导航，并为系统安全区及滚动内容留足空间。家长设置独立放在设置图标或侧栏底部，修改权限仍由服务器判断；孩子只能打开家长登录入口。账号菜单展示当前身份并提供退出。

作业首页先显示日期、下一步简短提示、交作业/拍备忘录。作业进展同时显示照片接收与完成状态，已有批改入口及错题本仍保留；不能将照片已收到等同已完成或已做对。识别依据、档案及旧记录按需进入详情，不在首页重复。首页严格采用选定稿的单列手帐：桌面内容区最大880px（含左右留白），不设置阅读右侧栏。阅读便签与小脚步并排放在清单下方；上传按钮约54px高，去掉重复副文案；“交作业”实心底色为略浅的玫瑰粉 #bb536e，保留清楚的暖白文字。清单保留照片和完成状态两个维度，每行并排显示科目、名称、铅笔与状态。超过3项时默认展示前三项，并显示总数及已完成项数，其余通过明确的展开按钮查看；展开后各项状态和修改入口仍可用。仅使用已登录家庭的真实记录，不放演示分数或虚构书籍。资料暂不可用时只显示入口。首页按选定参考图保留左侧“新的一页，开始啦”、两行寄语和简短提示，右侧大花盆与胶带，横线贯穿两侧；手机适配时寄语也保持两行。花盆保持旧版可辨认尺寸（桌面225px宽插画，手机按比例缩放）。点击小花盆才展开三款贴纸，浮层不挤动作业入口；选择后收起，支持点击外部、键盘Escape或移出焦点关闭。三款贴纸仅为设备上的个人装饰偏好，按账号保存，不代表奖励、积分或作业完成情况；不能访问本地存储时仍可使用。

作业、阅读与成长在同一学习空间内切换，不重新加载网页；进入后预先打开另一个空间，切换立即显示已有内容，后台刷新数据。保留正在编辑的页码、概括、照片及计时状态，地址和浏览器前进/后退同步。非当前空间暂停轮询，慢请求未结束时不叠加定时请求；阅读秒表只更新自身，不每秒重画整页。有未保存的阅读内容时离开页面触发浏览器提醒，阅读计时仍按原有设备恢复规则运行。更换登录账号重新读取资料并清理前一身份的编辑状态。书籍进展、连续记录、心愿及小脚步来自现有接口，界面改造不修改积分规则或历史记录。

小步入口在各页保持同一位置，通过导航打开现有对话窗，普通打开/关闭不清空对话或草稿。手机继续为对话保留主要空间，设置、记忆、导出和照片重看收在更多功能里；窄屏、横屏及软键盘高度变化均需验证。阅读场景使用阅读问题示例，不混入作业问题。

触控动作至少44像素高，阅读表单控件限定在卡片及标签内，480px以下书名和日期分行，避免本地化日期撑出卡片；日期保留原生选择器。输入框16像素以上，正文以16像素为基准。按钮保留文字和图标，禁用/等待有明确反馈。真实上传继续直接打开设备选择器，再确认上传，不重复要求日期、科目和关联任务。装饰插画保持轻巧，优先让孩子看见操作与真实进展；避免悬浮入口遮挡内容、无依据的学习评分和催促排名。

发布前使用隔离模拟家庭检查320、390、768、900及1280宽度，覆盖真实上传协议、家庭权限、阅读草稿/计时、许愿审批/兑换、对话/语音/导出及历史功能。测试资料不进入正式数据库。

备忘录条目保留简短铅笔“修改”入口，清单标题旁提供全清单入口。照片及完成状态都以至少44px高的按钮呈现，点击立即弹出具体解释，支持键盘、重复打开关闭和浏览器返回。不要用不可点击的问号图标暗示帮助入口，也不要用“未找到”混淆未上传与未匹配。直接编辑页只显示科目、名称和要求，较少使用的作业形式收在展开项中；失败保留表单，保存后自动整理并提供撤销。

所有弹窗共用底层页面滚动锁，包含作业原图、状态解释、修改备忘录、阅读选书、许愿及小助手。弹窗内部允许滚动，顶部/底部及遮罩上的拖动不能传给底层；叠加弹窗关闭最上层时继续锁住背景，最后一个关闭后恢复原滚动位置。保留输入选择、缩放和弹窗内的长内容滚动。

添加到桌面的独立窗口在页面顶部支持下拉刷新，超过阈值后松开触发；短拖、横滑、多指、取消、正在编辑的控件、嵌套滚动区和弹窗不触发。普通浏览器保留自身刷新手势。学习空间顶部提供44px刷新图标，配“正在刷新／已更新／失败重试”反馈，连续操作不叠加。刷新只读取当前空间的记录，不重新加载页面或触发AI整理，保留作业日期、阅读草稿/照片/计时及聊天；20秒未响应终止本次刷新，可重试。


## 系统配色与输入区域

页面通过 `prefers-color-scheme` 跟随设备的浅色、深色设置；切换不刷新页面，不清空正在填写的阅读或作业说明。浅色模式保留暖纸底，输入框使用稍深的暖纸色；深色模式使用暖灰底、柔粉色强调及独立的输入区域。共用配色位于 `src/app/theme.css`，原组件颜色保留浅色回退值，夜间使用语义颜色变量。原生日期、下拉选择等控件设置对应的 `color-scheme`；浏览器顶栏使用分模式的 `theme-color`。

正确、错误、未作答、未确认保留图标和各自色相，深色下调整文字与底色的对比度。输入框的聚焦、占位文字、停用和自动填充状态共用配色。打印继续使用白底。浏览器验收 `tests/browser/system-theme-ui.mjs` 使用模拟数据覆盖实时切换、草稿保留、文字对比度、手机与桌面、弹窗、小助手、家长登录和打印；其他支持配色的验收脚本可通过 `SMOKE_COLOR_SCHEME=dark` 检查夜间显示。

### 页面大模块与内容项目

阅读、成长、商城的大功能直接排在手帐纸面上，通过标题、留白及横向细分隔线分组，不使用多层带边框的大卡片。书籍、活动、商品、成长数据与心愿等具体项目使用柔和色块，颜色跟随系统深浅色。商城仍保持手机双列和紧凑比例。表单字段与弹窗的可操作边界、保存回执及状态语义不随大模块去框而取消。


### 按钮按用途分层

共用角色位于`src/app/journal-buttons.css`。保存、提交、查询、重试等明确执行的操作默认用深色实底与浅色文字，按当前界面选择玫瑰粉、暖棕、梅紫等色调，可执行的主按钮至少44px高。取消、返回、翻页、关闭和其他工具入口采用轻量样式。删除最终确认使用深玫红和明确的后果说明。暂时不可用的操作降低颜色强调并说明原因。小脚步不足、名额用完和到期在兑换弹窗里呈现为带图标的状态，余额不足同时显示还差多少。

颜色方案统一，不强制每个按钮同色：阅读计时使用暖棕实底按钮，按钮与提示直接排在纸面，不额外套有底色的容器，成长活动沿用灰绿、暖棕、豆沙粉、灰紫。卡片选择、导航、开关和状态标识保留原语义，不因按钮规范机械填色。计时／活动的上下文样式在`journal-sections.css`覆盖通用角色。

小步聊天入口采用原创兔子加对话气泡，手机隐藏长文字但保留气泡和“问问小步”无障碍名称；桌面保留文字。入口与教程、刷新、账号、设置同行，不另占一行，不遮挡内容。

手机顶部聊天、教程、刷新和设置统一可见正方形底色：通常40×40px，359px及以下34×34px，垂直透明命中区域保持44px。图标与兔子气泡居中，账号头像保留圆形；桌面带文字的聊天入口保持适合文字的宽度。


页面主标题采用同一规格：作业、阅读、成长、商城均为27px／650字重／1.4行高／-0.8px字距；600px及以下24px，359px及以下21px。品牌“小步学习”桌面21px、手机20px，360px及以下18px，保持顶部工具同行。阅读连读状态采用小芽和浅绿胶囊，占用原状态位置，不另增大卡片。

四页主标题右侧的日期、连续天数、余额共用`study-heading-badge`：128×44px、12px圆角、20px图标、同一内边距及垂直位置，切换页签保持稳定。日期显示统一为YYYY/MM/DD，点击整个日期块仍打开系统原生日期选择；保留无障碍标签、键盘焦点和16px原生输入字号，避免手机自动放大。此区域不各自定义宽高。
